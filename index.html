Supavision v1.0.3 ↓

Catch slop before committing.

Supavision is a desktop diff reviewer for Claude Code — built to shorten the loop between prompt and ship. Annotate changes line by line, and the review arrives inside Claude the moment you return to the prompt.

Download for Mac ↓

What it touches

Everything runs on your Mac. No account, no telemetry.

~/.local/bin/supavision
A shell script that opens the app. Written once, and never over a file that is not ours.
~/.claude/sessions
Read only, to find your running sessions and deliver the review over their socket. No hooks, no skills, no settings changed.
<repo>/.supavision/
Drafts and reviews. Excluded from git, so it never shows in a diff.
Network
The update check, from GitHub releases, signed. Nothing else.
